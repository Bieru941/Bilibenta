# BiliBenta Web Preview

This folder is a lightweight browser version of BiliBenta. It does not require Flutter.

## Run
Open `web/index.html` directly in a browser, or use VS Code Live Server.

## Supabase
The UI is currently a frontend preview. To make login, listings, image uploads, chat, and orders functional, connect the JavaScript app to your Supabase project using the Supabase JavaScript client and your public publishable/anon key.

Never put a Supabase service-role key in browser code.
